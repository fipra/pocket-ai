How distillation works here
A larger teacher model writes example answers. You review them, then train the smaller student model on those question and answer pairs.
    
    
  1. 1. Choose the teacher
    Choose a local GGUF or an OpenRouter model below. The same saved API key works in both Laboratory tabs.
    2. 
    
  2. 2. Prepare and review examples
    Use questions people will really ask. Check every answer, remove mistakes, and add different phrasings. Online teachers receive the questions or topic you enter.
    3. 
    
  3. 3. Send examples to the student
    Generate answers below, review them, then choose “Use these answers for fine tuning.” You can also import an existing JSON file in Fine tuning.
    4. 
    
  4. 4. Train and test
    Fine tune the smaller student (currently Qwen2.5 0.5B), test with questions outside the dataset, correct mistakes and train again. When satisfied, create the GGUF for the local chat.

Instructions for an external teacher
Use only a teacher whose terms permit training another model. Replace the placeholder with your questions and copy the request into that model.
JSON format for an online teacher
Save a UTF-8 .json file with at least five question and answer pairs, then import it in Fine tuning. “prompt” is the question; “completion” is the checked answer.
