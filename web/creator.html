Build a model from scratch

Train a small Transformer using your own data and no pretrained weights. Results depend on data and compute; a small model will not match a pretrained assistant.

Runs locally on Mac or Windows with Python and PyTorch installed. The native model is for this laboratory; it is not a GGUF and cannot yet be used in LlamaNest Web.

1. Configure model

The tokenizer uses UTF-8 bytes and four special markers; extra vocabulary slots remain unused. Memory is an estimate.

2–3. Import and validate dataset

Q&A: CSV, JSON or JSONL with question and answer fields, or tab-separated TXT. Text mode: TXT lines or records with a text field. At least three distinct examples are needed.



4–5. Train and monitor
Resume uses the saved architecture and dataset. Checkpoints are saved after each epoch; stopping during an epoch keeps the previous checkpoint.
Green: training loss · blue: validation loss · amber: gradient norm · purple: learning rate
Each line uses its own scale; exact values appear above.
Advanced: parameter values before and after the last update


6. Evaluate
Use the held-out split or import unseen examples in the same format. Exact matches, question overlaps, token loss and perplexity are measured; semantic correctness requires human review.


7. Chat with your model
Each prompt is answered independently; earlier chat turns are not passed to the model.


8. Save and export
Checkpoints are saved locally and can be reloaded here. Export downloads the native PyTorch checkpoint with architecture, tokenizer, weights, training metadata and optimizer state. Load only checkpoints you trust.
