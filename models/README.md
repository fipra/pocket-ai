# Models

Put compatible instruct `.gguf` weights here. GGUF files are ignored by version control. The app can also download the pinned default Qwen2.5 0.5B model from its interface; its source, size, and SHA-256 are recorded in `default-model.json`.

Check the license of each model before distributing a portable package. `QWEN-LICENSE.txt` applies to the default Qwen model.
