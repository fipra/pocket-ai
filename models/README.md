# Models

Put compatible instruct `.gguf` weights here. GGUF files are ignored by version control. The app offers four curated models from 0.5B to 9B; their sources, sizes where known, and SHA-256 hashes are recorded in `catalog.json`.

Check the license of each model before distributing a portable package. `QWEN-LICENSE.txt` applies to the 0.5B Qwen model; the 3B Qwen and 9B Gemma catalog entries have different licenses shown in the app.
