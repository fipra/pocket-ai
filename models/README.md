# Models

Put compatible instruct `.gguf` weights here. GGUF files are ignored by version control. The app includes one verified test download, Qwen 2.5 0.5B. Its source, exact size, and SHA-256 hash are recorded in `catalog.json`. Other GGUF models can be imported or found through search.

Check the license of each model before distributing a portable package. `QWEN-LICENSE.txt` applies to the 0.5B Qwen model; the 3B Qwen and 9B Gemma catalog entries have different licenses shown in the app.
