# Changelog

## 0.1.0 — Rust edition

- Replaced the Electron/Node application with a Rust localhost application and browser interface.
- Added local GGUF chat through `llama-cli`, document import and keyword retrieval, portable workspace, and Markdown export.
- Added an explicit, verified default-model download with progress display.
- Added macOS and Windows portable packaging scripts.
- Added a four-model catalog, hardware-aware recommendations, and a redesigned chat interface.
- Added automatic macOS Apple Silicon and Intel portable ZIP builds and releases.
- Added an automatic Windows x64 portable ZIP build and release, with bundled runtime tools.
- Added English as the default interface language, with saved choices for Italian, German, French, and Spanish; the selection also guides model responses.
